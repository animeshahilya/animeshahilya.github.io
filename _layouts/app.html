How to install

Choose one way. The first one keeps the app up to date for you.

Option 1: Obtainium (recommended, updates automatically)

Obtainium is a free app that installs apps from GitHub and keeps them updated.

  1. Install Obtainium.
  2. On your phone, open this link: Add {{ page.app_name }} to Obtainium. Or in Obtainium, tap “Add App” and paste {{ repo }}.
  3. Tap Install.

Option 2: From GitHub

  1. Open the latest release.
  2. Under “Assets”, download the file ending in .apk.
  3. Open the file. If Android asks, allow your browser to install apps.
